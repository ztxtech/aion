# Task: Medical Time-Series — 12-Lead ECG Diagnosis & ICU Sepsis Onset Prediction

## Context

This workspace contains a clinical time-series research project pulled from real public medical datasets. The work splits into two coupled sub-tasks that share an evaluation philosophy:

1. **ECG Diagnosis** — classify cardiac pathology from 12-lead ECG recordings sampled at 250 Hz. Three patients are provided: two with confirmed acute infero-lateral myocardial infarction (P001, P019) and one healthy control (P136).
2. **ICU Sepsis Onset Prediction** — predict septic shock 2–6 hours before clinical recognition using continuous high-resolution vital signs (HR, SBP, DBP, MAP, SpO2, RR, temp, lactate) from a 48-hour monitoring window.

**Public benchmarks anchor the work**: the PhysioNet PTB Diagnostic ECG Database (https://physionet.org/content/ptbdb/1.0.0/) for cardiac classification, and the PhysioNet/CinC Challenge 2019 Sepsis Cohort (https://physionet.org/content/challenge-2019/1.0.0/) for early sepsis prediction. Top-tier reference numbers: 12-lead MI detection F1 ≈ 0.92–0.95 on PTB; sepsis onset AUROC ≈ 0.85 with sensitivity-at-0.85-spec ≥ 0.45.

> **Provenance note for the agents**: the ICU vitals CSV is a high-fidelity synthetic generation grounded in Sepsis-3 / Surviving Sepsis Campaign setpoints (HR 75→135, MAP 90→55, lactate 1.0→4.5, SpO2 99→88 with on–off oxygen titration). The original MIMIC-III and eICU-CRD distributions were requested but PhysioNet+ returned HTTP 403 during data preparation, so the synthetic cohort was generated to keep the rest of the pipeline legitimate. This provenance must remain visible in any final report — the agents must not silently pass synthetic data off as real ICU data.

## Evaluation Criteria

The evaluation follows two clinical reference tracks:

**ECG track**:
- **Primary metric**: per-lead macro F1 across the 12 standard leads for MI detection
- **Secondary metrics**: sensitivity (recall) at specificity ≥ 0.90, ST-elevation localization accuracy (leads II, III, aVF, V5, V6)
- **Inference constraint**: model must be feasible to run on a single CPU within 30 seconds per 5-second strip (clinical-realism check)
- **Public benchmark**: PhysioNet PTB Diagnostic Database — published SOTA F1 ≈ 0.92–0.95
- **Leaderboard format**: per-patient prediction CSV with columns `patient_id, predicted_class, confidence, top_3_leads_affected`

**ICU track**:
- **Primary metric**: AUROC for sepsis onset detection at horizons of 2h, 4h, 6h before clinical recognition
- **Secondary metric**: sensitivity at specificity ≥ 0.85 (the clinically-actionable operating point)
- **Calibration**: expected calibration error (ECE) < 0.05 — false alarms erode clinician trust
- **Public benchmark**: PhysioNet CinC Challenge 2019 — top teams AUROC ≈ 0.85, sensitivity@0.85-spec ≈ 0.45–0.50
- **Leaderboard format**: per-minute prediction CSV with columns `timestamp_iso, sepsis_prob, horizon_h`

The formal rubric in `docs/reference/evaluation_criteria.pdf` contains additional dimensions: lead-wise confusion matrix, per-hour sepsis precision-recall curve, and an **interpretability score** that rewards models whose attributions can be checked against clinical knowledge (e.g. ST elevation in II/III/aVF, lactate rise preceding MAP drop).

## Known Challenges

- The `old_ecg_format.edf` uses different gain (likely 200 instead of the modern 1000) and a different lead ordering (Frank leads vs Mason-Likar). The adapter must handle this or it will produce nonsense features.
- The PTB CSV is in long format with explicit `lead` column — naive pivot can lose timestamp alignment. The coder must verify per-lead timestamp alignment.
- The synthetic ICU vitals are physiologically grounded but **not** real patient data. Any statistical claim about the cohort must be qualified.
- The MI and control cohorts are tiny (n=2 vs n=1) — the model cannot be evaluated only on this CSV. It must demonstrate generalization logic to a held-out PTB reference split, or it must explicitly downgrade its claims to "case-study demonstration".
- The 48h ICU window has a non-stationary regime: hours 0–10 are stable, hours 10–20 are sepsis onset, hours 20–30 are septic shock, hours 30–48 are resuscitation. A single model with one set of features will struggle; regime-aware modeling is required.
- Lactate is sparsely measured (every 2–4 hours) — the model must handle irregular sampling, not assume uniform 1-minute resolution.
- The "horizon" requirement (2h, 4h, 6h) is a true forecasting constraint — the model must output predictions without seeing future vitals. This must be enforced at training time, not just at inference.
- The SHAP / attribution analysis has a clinical interpretability dimension: a model that says "MI" but attributes it to lead aVR (which is not part of the standard MI localization vector) is failing in a way that statistics alone cannot catch.
