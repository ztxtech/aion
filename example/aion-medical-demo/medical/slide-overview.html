AION Medical Demo — Case at a Glance

Demonstration · not for clinical use

1Task setting

A clinical time-series investigation with two coupled sub-tasks sharing one evaluation philosophy: 12-lead ECG diagnosis of myocardial infarction from 250 Hz strips (PhysioNet PTB Diagnostic DB, 3 patients: 2 acute infero-lateral MI + 1 healthy control) and ICU sepsis onset prediction 2–6 hours before clinical recognition from continuous vital signs over a 48-hour window (PhysioNet CinC Challenge 2019 reference structure). The agent must demonstrate the full AION harness — planning, multi-agent review, governance gates, retrospective plots, sealed report — on this case.

2Inputs

  • ecg_signals.csv · 12 leads × 5s @ 250 Hz, 3 patients (real PTB)
  • ptb_ecg/patient*/ · raw WFDB .dat/.hea/.xyz
  • icu_vitals.csv · 48h @ 1-min, 7 channels + sparse lactate
  • old_ecg_format.edf · legacy EDF, different gain & lead order
  • manual_corrections.json · 8 cardiologist beat annotations
  • docs/reference/ · 7 clinician-provided PNGs + rubric PDF

3Requirements

  • Unify 4 input formats into one data contract (data/interface.py)
  • Compare ≥3 statistical + 3 classical ML + 3 deep / TFM routes per track
  • Foundation-model precheck: zero-shot / few-shot / frozen / light-adapt
  • Honour the 2h / 4h / 6h horizon — no future-vitals leakage
  • SHAP / IG attribution that localises to the right leads
  • Document failure modes — missed MI / sepsis cost is asymmetric

4Expected outputs

  • outputs/ecg_submission.csv · 3 rows, top_3_leads ⊂ {II, III, aVF, V5, V6}
  • outputs/icu_submission.csv · 2h/4h/6h horizons, monotonic rise at h18–22, ECE < 0.05
  • docs/images/ · 4 plots consumed in the report
  • docs/report.md · disclaimer, provenance, method table, failure modes
  • REBUTTAL.md · trace.jsonl · memory/ for c-critic sign-off

5Challenges for the agent

  • Tiny cohort (n=2 vs n=1 ECG) — downgrade claims, demonstrate structure
  • Synthetic ICU vs real ECG — provenance must travel with the data
  • Sparse lactate (16 / 48h) — irregular sampling, not uniform 1-min
  • Non-stationary regimes — stable → onset → shock → resuscitation
  • Asymmetric clinical cost — missed MI > false alarm, encode it
  • Legacy EDF gain mismatch — silent nonsense if adapter is sloppy
